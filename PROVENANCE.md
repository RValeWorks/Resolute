# Provenance

Resolute is the owner's original and commissioned project. Its Nuclear Option integration and the original replacement artwork were prepared for that project. The public repository includes the integration code used in the matching release DLL, without obfuscation. The owner retains the ship and art assets; editable models and art sources are not included.

The released life-raft visuals are the original Resolute replacement, including its corrected lettering. Their historical loader filenames do not imply that the previous reference mod's raft artwork is included.

Nuclear Option's native definitions, shaders, materials, effects, sounds and game logic are accessed from a legitimate local installation. No game executable, game DLL, extracted game artwork or decompiled game source is included here. BepInEx and Harmony are separate runtime/build dependencies and are not bundled in these repositories.

Dependency projects:

- [Nuclear Option / Shockfront Studios](https://store.steampowered.com/app/2168680/Nuclear_Option/)
- [BepInEx](https://github.com/BepInEx/BepInEx)
- [Harmony](https://github.com/pardeike/Harmony)

The source manifest records the compiler inputs matching the release DLL. Local test logs, build-machine paths and private asset archives are omitted. A public source release does not transfer ownership of the artwork.
